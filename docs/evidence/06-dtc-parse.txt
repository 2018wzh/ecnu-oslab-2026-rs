################ fdtget (libfdt, U-Boot 内部用的库) 按数字读取 ################

dtc 把 load/entry 显示成 "@ ", "" 是它的**显示启发式**, 不是镜像的问题:
0x40200000 的大端字节是 40 20 00 00 = '@', ' ', NUL, NUL。
FDT 的属性没有类型 —— 类型知识在读它的驱动手里。

$ fdtget -t x kernel.itb /images/kernel load           -> 40200000
$ fdtget -t x kernel.itb /images/kernel entry          -> 40200000
$ fdtget -t x kernel.itb /images/kernel data-size      -> 6498
$ fdtget -t x kernel.itb /images/kernel data-offset    -> 2b0
$ fdtget -t x kernel.itb /images/kernel data-position  -> 2b0

$ fdtget -t s kernel.itb /images/kernel type           -> kernel
$ fdtget -t s kernel.itb /images/kernel arch           -> riscv
$ fdtget -t s kernel.itb /images/kernel os             -> linux
$ fdtget -t s kernel.itb /images/kernel compression    -> none
$ fdtget -t s kernel.itb /configurations default          -> conf-1
$ fdtget -t s kernel.itb /configurations/conf-1 kernel    -> kernel
